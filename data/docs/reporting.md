# Reporting

## Overview
The reporting workflow generates platform documents based on a selected program, date range, and report type. Common report types include entrance notifications, progress reports, exit notices, completion documents, and unexcused absence notices.

## How report generation works
A user chooses a program, selects a date range, and chooses one or more report types. The system loads the relevant client data, applies business rules for each report type, renders document templates, and stores the final files for download or delivery.

## Common failure points
Report generation can fail when required templates are missing, client data is incomplete, a date range excludes all matching clients, or document conversion to PDF fails.
