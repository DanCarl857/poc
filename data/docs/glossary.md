# Glossary

## Client
A client is a person enrolled in one of the platform's programs and tracked across intake, attendance, reporting, and exit workflows.

## Program
A program is a defined treatment or education track, such as Anger Control, Thinking for a Change, or BIPP.

## Report Generation
Report generation is the workflow that creates program documents for a given date range and output type.

## Exit Reason
An exit reason explains why a client left the program. Common examples include completion, moved, death, unable to participate, and violation of requirements.
